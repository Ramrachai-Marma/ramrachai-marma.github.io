# Portfolio Website

This is a simple, professional portfolio website built as a static HTML/CSS/JavaScript site.

## Structure

- `index.html` — landing page with hero, projects, about, skills, and contact sections.
- `styles.css` — responsive styling and layout.
- `script.js` — small navigation enhancement.

## Customize

Update `index.html` with your name, role, project descriptions, and contact email.
Update `styles.css` to change colors, fonts, or layout details.

## Deploy to GitHub Pages

1. Create a new GitHub repository for your portfolio.
2. Add this project folder to the repository and push to the `main` branch.
3. In GitHub, go to `Settings` > `Pages`.
4. Under `Build and deployment`, choose source `Deploy from a branch`.
5. Set branch to `main` and folder to `/ (root)`.
6. Save and wait for GitHub Pages to publish your site.

Your site will be available at `https://<username>.github.io/<repository-name>/`.

## Optional

- Rename the repository to `<username>.github.io` to publish at `https://<username>.github.io/`
- Add a `CNAME` file if you want a custom domain.
